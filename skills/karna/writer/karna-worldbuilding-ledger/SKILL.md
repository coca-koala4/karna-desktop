# Worldbuilding Ledger

用于 Karna 的写作/编辑工作流；本技能只读取本地上下文，不执行外部代码。它保持本地、可审计、可复用，适合在桌面端直接启用。

## Workflow
1. Identify the writing role and deliverable: novel, poem, script, paper, article, web copy, or editorial note.
2. Ask for missing constraints only when they change the result: audience, genre, length, tone, canon, citation style, deadline.
3. Produce structured intermediate artifacts before final prose: outline, beat sheet, argument map, style rules, or revision checklist.
4. Preserve the user's voice. When rewriting, explain the editorial move instead of flattening the text.
5. Track open questions, continuity risks, source/evidence gaps, and next revision actions.

## Output contract
- Start with the practical artifact the writer needs now.
- Keep a short "why this works" note for revision literacy.
- For long projects, maintain reusable canon/style/decision bullets that can be pasted into the Karna 知识库.
