# find-skill

用于在 Karna 桌面端内查找本地可用技能。

## 使用场景

- 用户不知道该用哪个 skill。
- 用户描述写作、编辑、论文、编剧、文案等任务，需要推荐技能。
- 需要检查技能是否已经存在，避免重复创建。

## 工作流程

1. 提取用户关键词、任务类型、产物类型。
2. 调用 `/api/skills/search?q=...` 或 `/find-skill ...`。
3. 返回技能名称、说明、路径、启用状态、推荐理由。
4. 如果没有匹配，建议使用 `create-skill` 创建新技能。
