# Karna 2.0.1 发布说明

## 发布日期
2026-07-20

## 版本号
2.0.1

## 主要修复

### 1. 复杂多智能体工作流崩溃问题
- 重构工作流执行引擎，增强循环检测能力
- 实现DAG执行稳定性保障，添加节点级错误边界
- 添加节点执行超时保护（默认10分钟/节点）
- 限制并行执行节点数（最多5个），防止资源耗尽
- 新增工作流运行状态持久化，支持暂停/恢复/停止
- 修复"多评审师循环修订"等复杂工作流导致的程序无响应问题

### 2. 应用内自动更新功能修复
- 修复设置中"检查更新"功能无法检测新版本的问题
- 完整实现 `/api/updates/check` 端点，连接electron-updater
- 添加更新下载和安装端点
- 支持后台自动下载更新，下载完成后提示安装
- 支持每6小时自动轮询检查更新

### 3. 离线运行时修复
- 修复离线runtime从hermes-agent到karna-runtime的迁移逻辑
- 修复Python venv内examples等目录被错误过滤的问题
- 添加多源查找逻辑，支持从旧release目录复用runtime
- 完善runtime品牌化替换逻辑

### 4. 构建系统优化
- 添加ALLOW_DIRTY_BUILD环境变量支持本地开发构建
- 修复verify-version-consistency脚本，添加--allow-dirty参数
- 优化release内容验证，开发构建模式下只警告不中断
- 修复MSI构建时wix缓存权限问题（默认仅构建NSIS）

### 5. 版本一致性保障
- 统一版本号为2.0.1，确保package.json、runtime-manifest等一致
- 修复构建时版本号同步逻辑
- 添加构建前版本校验步骤

## 更新方式
1. 打开Karna应用
2. 进入设置 → 关于
3. 点击"检查更新"
4. 等待下载完成后点击安装

## 文件清单
- `Karna-2.0.1-win-x64.exe` - Windows安装包（NSIS）
- `Karna-2.0.1-win-x64.exe.blockmap` - 增量更新块映射
- `latest.yml` - 更新清单文件
